Web Technologies

HTML

Html is the standard markup language used to create and structure web pages. It acts as the the architectural blueprint of a website. Markup language, meaning it simply annotates text to tell a browser how to organize and display content.

CSS

CSS stands for Cascading Style Sheets. It is the standard style sheet language used to determine the visual presentation, layout, and design of web pages. CSS is one of the three core technologies of the World Wide Web.

JavaScript

JavaScript is a powerful programming language used to create interactive and dynamic content on websites. Enabling features like animated graphics, interactive forms, and real time content updates without reloading the page. JavaScript is the programming language that makes websites interactive and alive.
